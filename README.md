
# Matter Environment Sensor

based on nRF SDK 3.3.0 Matter temperature example

## Features

- nRK Connect SDK 3.3.0
- XIAO nRF54LM20A
- BME280 breakout board for temperature/humidity measuring
- Battery voltage monitoring with nPM1300 PMIC
- Low power: around 25µA current consumption with 15 seconds update interval
